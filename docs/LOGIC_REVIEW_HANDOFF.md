# Передача на независимую проверку логики

Цель: провести отдельный adversarial review готовой первой версии «Борт». Работать только в рамках текущего статического прототипа; не добавлять новые функции. Сначала выдать находки и сценарии воспроизведения, затем предложить минимальные исправления. Не публиковать и не коммитить новые правки без отдельного согласования.

## Файлы для чтения

- `dist/core.js` — быстрый пересчёт, Fuelio/JSON импорт, распознавание профиля, интервалы топлива.
- `dist/app.js` — формы, UI-предпросмотр, merge/replace, localStorage, доходы.
- `dist/report.js` — локальный HTML для покупателя.
- `dist/sw.js` — обновление кэша и offline fallback.
- `tests/core.test.js`, `tests/report.test.js`, `QA.md`.

## Приоритетные проверки

1. **Пересчёт заправки:** изменить по очереди сумму, литры и цену за литр; поля с введённым значением не должны самопроизвольно перезаписываться после округления. Проверить пустые, нулевые, очень большие и некорректные числа.
2. **Топливные интервалы:** полные/частичные/пропущенные заправки; несколько записей в один день с временем, без времени, обратным порядком CSV и одинаковым одометром; неизвестный/нулевой/отрицательный пробег и объём; убывание одометра; корректные `from`, `to`, литры, ₽/км и л/100 км.
3. **Импорт Fuelio:** варианты заголовков `##`, optional-полей, quoted commas/newlines, пропуск пробега, доходов (`isIncome`), неизвестных секций, GUID-дублей и неподдерживаемых единиц. Сравнить предпросмотр и результат замены/добавления. Проверить сравнение машин с разным регистром, пунктуацией и годом.
4. **JSON и хранение:** невалидная дата/категория/числа, дубли id/GUID, HTML в текстовых полях; повреждённый localStorage; отказ чтения и записи localStorage для добавления, правки, удаления, импорта и профиля. Проверить, что ошибки не дают ложного сообщения об успехе и откатывают состояние.
5. **Демо:** добавить реальную запись (примеры очищаются), изменить запись-демо (метка сохраняется), восстановиться из повреждённого сохранения без бесшумной подмены и последующей перезаписи.
6. **Отчёт:** в выбранном срезе только «Сервис», сумма только выбранных записей; plate/VIN/notes/location не попадают в HTML; заголовки экранируются; демо и неподтверждённая полнота истории обозначены; мобильная вёрстка и печать.
7. **PWA:** network-first для HTML/JS/CSS/manifest; обновление app.js/core.js как согласованной версии; проверка MIME перед offline fallback; очистка только собственных старых кэшей, не сторонних.

## Обязательные сценарии UI

- Создать заправку без названия, изменить сумму и пробег, обновить страницу, убедиться в одной сохранённой записи и удалить только тестовую запись.
- Импортировать Skoda с секцией Vehicle поверх профиля Volvo с номером; убедиться, что старый номер не наследуется.
- Отказать `localStorage.setItem` и повторить каждое изменяющее действие; убедиться, что интерфейс сохраняет прежнее состояние.
- Проверить интерфейс на 390×844 и 1440×960, затем открыть скачанный HTML-отчёт на телефоне и распечатать в PDF.
- Проверить обновление service worker при сети и запуск из offline после установки.

## Формат результата

Для каждой находки указывать severity, файл/строку, короткий сценарий воспроизведения, фактический и ожидаемый результат. Отдельно перечислить проверенные сценарии, непроверенные условия и точечные исправления. Реальный Fuelio CSV использовать только если владелец предоставит его отдельно; не копировать его в исходники или `dist`.
