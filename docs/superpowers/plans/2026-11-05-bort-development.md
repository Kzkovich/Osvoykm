> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Пользователь требует недорогую модель. Не подключать дорогих исполнителей или ревьюеров.

**Goal:** Выпустить проверенную адаптивную веб/PWA-версию журнала автомобильных расходов с быстрым вводом, импортом Fuelio, аналитикой и скачиваемой историей обслуживания.

**Architecture:** Продолжить существующий статический прототип, не переписывать его на фреймворк. Чистые расчёты и парсер находятся в core.js, интерфейс в app.js, отчёт в report.js. Данные первой версии хранятся локально в браузере с экспортом JSON.

**Tech Stack:** HTML, CSS, JavaScript, localStorage, service worker, Node.js built-in assert для тестов. Без сборщика и новых зависимостей.

**Spec:** /Users/alfa/dev/auto-journal/PRODUCT.md; решения пользователя в текущем чате имеют приоритет.
